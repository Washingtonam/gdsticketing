# First Cohort Approval Script

## Goal
Use this script each day to move students from payment to approved access with minimal delay.

## Step-by-step process
1. Open the admin payment review page.
2. Review all students listed in `paid_pending_approval`.
3. Check each student’s full name, course, and payment reference.
4. If the payment is valid, click `Approve access`.
5. Send the approval message immediately.
6. Ask the student to log in and begin lesson 1.
7. Record the approval in your daily tracker.

## Daily owner script
- Total pending approvals: ____
- Approvals completed today: ____
- Follow-up messages sent: ____
- Students with access now active: ____

## Escalation note
If a payment is listed but seems invalid, do not approve immediately. Escalate to the owner for confirmation before access is granted.
